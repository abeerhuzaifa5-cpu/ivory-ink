## 🔧 Troubleshooting Guide

### If dev server won't start:
1. Make sure `npm install` completed
2. Check that port 3000 is available
3. Try: `rm -rf .next && npm run dev`

### If 3D scene doesn't render:
1. Check browser WebGL support (most modern browsers support it)
2. Open browser console (F12) for error messages
3. Try a different browser

### If animations stutter:
1. Close other browser tabs
2. Check CPU usage (Task Manager)
3. Reduce particle count if needed

### If styling looks wrong:
1. Wait for Tailwind to compile
2. Hard refresh (Ctrl+Shift+R)
3. Check that tailwind.config.js wasn't modified
